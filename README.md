# MMD EXAM Fullstack React Native Project

This workspace contains a JavaScript fullstack project with:
- `api` — Node.js + Express backend
- `app` — Expo React Native mobile app

## Setup

1. Run `npm install` from the workspace root.
2. Start the backend: `npm run dev:api`
3. Start the app: `npm run dev:app`

## Notes

- The app is configured to run with Expo.
- The backend listens on port `3000`.
- Use `npm run dev` to start both app and backend in parallel.
